# CSCE 679 – Assignment 1: Hong Kong Temperature Heatmaps

Interactive visualizations of Hong Kong daily temperature data (1997–2017) using Python and Plotly

## Files

- temperature_daily.csv' – Raw daily temperature data (date, max, min)
- level1.py – Generates a year/month heatmap with max/min toggle and hover tooltips
- level2.py – Extends Level 1 with mini daily line charts embedded in each cell (last 10 years)
- level1.html – Level 1 output (open in any browser)
- level2.html – Level 2 output (open in any browser)

## How to Run

- pip install pandas plotly
- python level1.py
  - outputs level1.html
- python level2.py
  - outputs level2.html


Open the resulting .html files in a browser to view the charts
